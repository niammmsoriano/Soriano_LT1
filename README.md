# Soriano_LT1

## Description
This program calculates on how much notebooks are going to be put in a box and its box capacity and how much excess notebooks there are so it is going to be put in a loose pack.

##
How to run:

1. Open the program in VS Code, or any Compiler

   2. Run the program
  
   3. Enter the values asked for in the program
  
   4. Then it will show your total result.
  
  ## Sample output:
Enter the amount of notebooks: 120
Enter storage capacity of boxes: 10
There will be 10 boxes
